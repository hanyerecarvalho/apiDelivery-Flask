# Delivery API · Python

Proposta de API REST para um sistema de delivery, desenvolvida para a disciplina de **Programação Avançada para Web (PAW)**.

## Status

Este repositório contém, por enquanto, apenas a apresentação do projeto. O código da aplicação, as dependências e as instruções de execução ainda não foram adicionados.

## Escopo previsto

- CRUD de três entidades relacionadas.
- Autenticação com JSON Web Token (JWT).
- Integração com banco de dados.
- Desenvolvimento em Python.

Esses itens descrevem a proposta; a implementação ainda não está disponível neste repositório.
